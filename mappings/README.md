# Operator Format Mappings

Each JSON file in this directory defines how to parse a specific operator's production report format and map it to the standardized 16-column ComboCurve template.

## File Naming Convention

`{operator-slug}-{type}.json`

Example: `anadarko-monthly.json`, `aftermath-daily.json`

## Schema

See the format mapping documentation in the project README for the full JSON schema.
